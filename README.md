# Northwind Traders – Sales Analysis

## Project Overview
This project focuses on analyzing Northwind Traders' sales data using Excel and Power BI to identify business trends, evaluate performance, and generate meaningful insights.

## Objectives
- Clean and transform raw sales data.
- Perform data modelling and establish relationships.
- Create DAX measures for business calculations.
- Analyze sales, profit, freight, and shipping performance.
- Build an interactive Power BI dashboard.

## Tools & Technologies
- Microsoft Excel
- Power BI
- Power Query
- DAX

## Analysis Performed
- **Descriptive Analysis:** Understand sales trends, revenue, and product performance.
- **Diagnostic Analysis:** Identify factors affecting sales and shipping performance.
- **Predictive Analysis:** Explore historical trends to understand potential future sales patterns.
- **Prescriptive Analysis:** Suggest business improvements based on identified insights.

## Key Deliverables
- Cleaned dataset
- Data model and relationships
- DAX calculations
- Interactive Power BI dashboard
- Project documentation

## Project Outcome
The project demonstrates practical data analytics skills, from data preparation and transformation to visualization and business insight generation.
